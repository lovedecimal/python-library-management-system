#Python库管理系统
这是一个轻量、可以自己定制的Python控制台版图书管理系统，不用装额外的依赖包就能用，核心能实现图书的添加、删除、修改、查询，还有借阅归还、库存预警这些功能，数据关掉程序也不会丢，特别适合Python新手拿来练手或者做课程设计。

## 项目介绍
这个项目是专门给刚学Python的同学做的实战小应用，全程只用Python自带的库，不用额外安装任何第三方包。和基础的图书管理系统比，这个版本加了不少实用的个性化功能：比如可以自己改系统名称、欢迎语，控制台里的文字会用不同颜色区分（比如成功提示是绿色、警告是黄色），借阅图书时会记录借阅时间和30天的归还期限，归还的时候还能自动算有没有超期，也能按小说、科技这些分类管理图书，代码里的注释很全，新手看也能看懂。

## 核心功能
- 图书基础管理：能添加、删除、修改、查询图书信息，包括编号、名称、作者、分类这些内容，系统会自动检查图书编号是否重复，库存数量也会做校验，避免输入负数这种错误。
- 借阅归还管理：借图书的时候会记录借阅人姓名、借阅时间，还会自动生成30天的归还期限；归还图书时会更新库存，还能算出有没有超期，超期的话会用红色字体提醒。
- 库存预警：如果某本图书的库存少于等于3本，系统会自动用红色标注，也能一键查看所有库存偏低的图书，方便及时补货。
- 多维度搜索图书：可以按图书编号精准找，也能按图书名称模糊搜，还能按分类（比如只看小说类图书）查找，找起来很方便。
- 借阅记录查询：输入借阅人的姓名，就能查到这个人所有借过的书，包括哪些书还没还、每本书的借阅时间和归还期限都能看到。
- 数据持久化：所有的图书信息和借阅记录都会自动存在JSON文件里，就算关掉程序，下次打开数据还在，不用重新录入。
- 个性化配置：不用改核心代码，只改代码最顶部的几个参数，就能自定义系统名称、管理员称呼、欢迎语，甚至图书的分类（比如想加“漫画”分类也可以）。

## 技术栈
整个项目仅使用Python 3.6及以上版本，完全依赖Python自带的内置库，无需额外安装任何包：
- 用json库存数据，把图书信息和借阅记录存在本地文件里；
- 用os库实现Windows、Linux、Mac不同系统的清屏功能；
- 用datetime库计算借阅期限和逾期天数；
- 用time库做简单的交互延迟，体验更友好。

## 快速开始
### 环境要求
请先在电脑上安装Python 3.6及以上版本（推荐安装3.8或更高版本）。安装时记得勾选“将Python添加到PATH”，这样在终端里就能直接运行Python命令了，Windows、Linux、Mac系统均可使用。

### 运行步骤
1. 克隆仓库：先打开终端（Windows是命令提示符或PowerShell，Mac/Linux是终端），输入下面的命令把仓库复制到本地，然后进入项目文件夹：
   ```bash
   git clone https://github.com/lovedecimal/python-library-management-system.git
   cd python-库管理系统
   ```
2. 直接运行：因为不用装第三方依赖，复制完直接输入运行命令就行：
   - Windows系统：输入`python my_library_manage.py`
   - Linux/Mac系统：输入`python3 my_library_manage.py`
3. 操作说明：运行后会看到系统菜单，按提示输入数字就能操作：
   - 输入1：添加新图书，需要填编号、名称、作者，还要选分类（比如小说、科技），库存数量填数字就行；
   - 输入4：借阅图书，输入图书编号和借阅人姓名，系统会自动扣库存，还会提示归还期限；
   - 输入7：查看库存预警，能看到所有库存≤3本的图书，方便补货；
   - 输入8：查自己的借阅记录，输入姓名就能看到借过的书、有没有还；
   - 输入9：退出系统，所有数据会自动保存，下次打开不会丢。

## 个性化配置
想改成自己专属的系统很简单，不用改核心功能代码，只改`my_library_manage.py`文件最顶部的“个性化配置区”就行：
```python
# 个性化配置区（可自行修改）
SYSTEM_NAME = "我的私人图书管理系统"  # 想改系统名就改这里，比如改成“XX学校图书管理系统”
ADMIN_NAME = "图书管理员小助手"       # 管理员称呼可以随便改
WELCOME_WORDS = "欢迎使用专属图书管理系统，让阅读更有条理～"  # 欢迎语自定义
EXIT_WORDS = "感谢使用，愿你与好书相伴，下次见！"            # 退出时的提示语
BOOK_CATEGORIES = ["小说", "科技", "教材", "历史", "传记", "其他"]  # 想加分类就加，比如加个“漫画”
```

## 项目结构
项目里的文件很少，结构很清晰：
- `my_library_manage.py`：这是主程序文件，所有功能都在这个文件里，直接运行这个文件就行；
- `my_library_books.json`：运行程序后会自动生成这个文件，所有图书信息、借阅记录都存在这里；
- `README.md`：就是这个说明文档，告诉你怎么用这个项目。

## 数据存储说明
-所有图书信息、谁借了什么书、有没有还，都会存在`my_library_books.json`文件里，退出系统时会自动保存，不用手动存；
- 如果想备份数据，直接复制这个JSON文件就行，要是不小心删了这个文件，所有数据就没了，需要重新录入；
- 这个JSON文件用的是UTF-8编码，存中文不会乱码，放心用。

## 常见问题（FAQ）
1. 问：运行后控制台里的文字乱码了怎么办？
   答：主要是Windows终端默认编码不是UTF-8，先在终端里输入`chcp 65001`切换成UTF-8编码，然后重新运行`python my_library_manage.py`就好了。
2. 问：Windows系统下，控制台里的文字没有彩色，都是黑白的怎么办？
   答：Windows终端默认没开ANSI转义支持，推荐用Windows Terminal运行；或者在PowerShell里输入`Set-ItemProperty HKCU:\Console VirtualTerminalLevel -Type DWORD 1`，重启终端再运行程序，就能看到彩色文字了。
3. 问：把代码保存成.py文件后，双击运行一闪而过，看不到界面怎么办？
   答：大概率是文件后缀没改对，看着是.py，其实还是.txt文件。先打开文件夹，点击“查看”，勾选“文件扩展名”，确保文件名是`my_library_manage.py`（不是`my_library_manage.py.txt`）；也可以用终端运行，能看到具体的报错信息，方便排查。
